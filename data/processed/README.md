# Processed 3NF & NoSQL Artifacts

This directory contains the structured artifacts generated by the ETL pipeline `etl/extract_and_transform.py`.

## Relational 3NF Architecture (MySQL 8.0)
The raw dataset is extracted, cleaned, and decomposed into 10 Third Normal Form (3NF) tables to eliminate transitive dependencies and redundant storage:
1. `brand.csv`: Unique brand identifiers and names (46 records).
2. `processor.csv`: Processor specifications, clock speed, core counts, and brands (91 unique configurations).
3. `os.csv`: Operating system classifications (Android, iOS, Other, Unknown).
4. `connectivity.csv`: Feature permutations for 5G, NFC, and IR Blaster (8 unique combinations).
5. `battery.csv`: Battery capacity and fast-charging ratings (228 unique configurations).
6. `screen.csv`: Screen sizes, refresh rates, and display resolutions (302 unique configurations).
7. `memory.csv`: RAM, internal storage, and expandable memory specs (94 unique configurations).
8. `camera.csv`: Rear/front sensor counts and primary megapixel ratings (158 unique configurations).
9. `phone.csv`: Central fact entity relating all dimension foreign keys to each smartphone model (980 models).
10. `price_analysis.csv`: Materialized brand-level market aggregates (min, max, average pricing, model counts).

## Document-Oriented NoSQL Architecture (MongoDB)
The ETL pipeline denormalizes hierarchical smartphone specs into `smartphones_mongo.json` following the embedded document pattern:
```json
{
  "_id": 1,
  "brand": "oneplus",
  "model": "OnePlus 11 5G",
  "price": 54999.0,
  "rating": 89.0,
  "specs": {
    "processor": { "brand": "snapdragon", "num_cores": 8, "speed_ghz": 3.2 },
    "display": { "screen_size_in": 6.7, "refresh_rate_hz": 120, "resolution_width": 1440, "resolution_height": 3216 },
    "battery": { "capacity_mah": 5000, "fast_charging_available": true, "fast_charging_w": 100.0 },
    "memory": { "ram_gb": 12, "storage_gb": 256, "expandable": false, "expandable_upto_gb": null },
    "camera": { "num_rear": 3, "num_front": 1, "rear_mp": 50.0, "front_mp": 16.0 },
    "connectivity": { "has_5g": true, "has_nfc": true, "has_ir_blaster": false },
    "os": "android"
  }
}
```

To regenerate all CSVs and the MongoDB JSON file:
```bash
python etl/extract_and_transform.py
```
